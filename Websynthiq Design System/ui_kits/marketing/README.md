# Websynthiq — Marketing UI Kit

A high-fidelity recreation of a marketing surface for Websynthiq.

> ⚠️ **No real product UI was provided.** This kit is **extrapolated** from the
> brand identity (logo, palette, dual-tone wordmark) into the most likely
> surface for a "Websynthiq"-style brand: a developer-leaning marketing site.
> When real screens are available, swap content and re-verify components.

## Files

- `index.html` — interactive demo, stitches the components into a marketing page
- `Nav.jsx` — top navigation bar
- `Hero.jsx` — hero section with brand banner treatment
- `FeatureGrid.jsx` — 3-up feature cards
- `CodeSample.jsx` — code-block showcase
- `LogoCloud.jsx` — partner / customer logos
- `CTASection.jsx` — call-to-action block
- `Footer.jsx` — site footer
- `ui.jsx` — shared atoms (Button, Badge, Eyebrow, Wordmark)

## Loading

The kit is plain JSX loaded via Babel. See `index.html` for the script-tag
setup.
